# dev

Early development and testing. Nothing here is part of Beyond Possession, and nothing here is needed to run it.

| Path | What it is |
|---|---|
| `nmstpp/` | An early reproduction of the NMSTPP event-prediction model from the OpenSTARLab paper, and a symmetry experiment built on it. It has its own README and runs on its own. |
| `datasets/` | The 1,941 Wyscout match records divided into training, test and validation sets (70 / 20 / 10), with the scripts that split and recombine them. The same records make up the match catalogue in `beyond-possession/data/real/`. |
